# Developer

Format, decode, hash and compare. Offline and instant.

## Tools
- [Hash Generator](./Hash Generator/README.md) - Create MD5, SHA-1 and SHA-256 hashes of text or files.
- [Diff Checker](./Diff Checker/README.md) - Compare two blocks of text and see what changed.
- [Base64](./Base64/README.md) - Encode and decode Base64.
- [JSON Formatter](./JSON Formatter/README.md) - Format, validate and minify JSON.

> The design shows 8 Developer tools; only 4 have been identified so far.
