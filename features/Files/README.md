# Files

Rename in bulk and make QR codes

## Tools
- [QR Code](./QR Code/README.md) - Make QR codes for links, text and Wi-Fi, or read codes and barcodes from images.
- [Batch Rename](./Batch Rename/README.md) - Rename many files at once with find and replace, numbering, dates or case changes.
- [Find Duplicates](./Find Duplicates/README.md) - Find identical files across folders and move the extras to the Trash.
- [Zip & Unzip](./Zip & Unzip/README.md) - Open ZIP, RAR, 7z and TAR files, or make a ZIP, with a password if you like.
